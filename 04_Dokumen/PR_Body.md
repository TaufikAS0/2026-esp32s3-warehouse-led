Adds an ESP32-S3 warehouse location indicator controlled by stable box IDs. One controller drives four WS2812B outputs, supporting 25 three-LED boxes per rack; initial configuration enables one box for staged bring-up.

Includes an embedded slate/cyan rack dashboard with100 visible positions, direct per-box mapping editor for all slots, selected-box control,3-second RGB/blink tests, per-LED setup presets, validated mapping drafts, authenticated HTTP API, bounded timers, NVS configuration, STA/AP recovery, opt-in OTA, and a Python client without write retries. Version is v0.4.0. User-approved internal AP default is12345678; actual router/API/OTA credentials stay private.

Validation: ESP32-S3 compile, C++ domain/codec,11 Python tests and embedded HTML/JS DOM suite pass. v0.4.0 actual device tests cover per-box label save, unchanged Wi-Fi, invalid mapping rejection, RGB/blink commands and expiry. Authenticated OTA upload succeeded, with reboot, retained mapping/Wi-Fi and closed OTA after boot; served HTML matches source. Browser manual control was verified on v0.3.2; v0.4.0 visual recheck was blocked by the Codex browser connection. See04_Dokumen/Test_Report.md for evidence and limits.

No active JARVIS source changes. Optical LED output,75/300 LED/RMT behavior, power distribution, full network recovery and8-hour endurance remain open; this PR is a software baseline, not a production certification.
