Includes an embedded slate/cyan rack dashboard with100 visible positions, direct per-box mapping editor for all slots, per-rack installed-LED hardware tests, firmware version visible before API connection, selected-box control,3-second RGB/blink tests, per-LED setup presets, validated mapping drafts, open LAN HTTP API as explicitly requested by the user, bounded timers, NVS configuration, STA/AP recovery, opt-in OTA, and a Python client without write retries. Version is v0.5.0. User-approved internal AP default is12345678; actual router/API/OTA credentials stay private.
